JYLY COFFEE WEBSITE

1. Extract JYLY_Coffee_site.zip.
2. Open the JYLY_Coffee folder.
3. Open index.html in Chrome, Safari or another browser.
4. Keep index.html, style.css, script.js and assets/ together.
5. For hosting, upload the entire folder to any static website hosting.

Kazakh / Russian switch, category filtering, search, image gallery,
cart and WhatsApp checkout are included.

IMPORTANT:
- Prices for selected cards were transcribed from screenshots and should be verified.
- Some drinks have multiple sizes: cards show the starting price.
- Full original menu pages are in the photo gallery.
- Map iframe shows a general Kyzylorda area; the 2GIS link opens the exact cafe.
- Delivery cost is confirmed by the cafe on WhatsApp.
- Fonts use Google Fonts; fallback fonts work offline.
